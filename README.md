# 플래피 버드

파란 낮하늘을 날아가는 픽셀 아트 플래피 버드. 날갯짓으로 높이를 맞춰 파이프 사이를 통과하세요.

## 조작
| 키 / 입력 | 동작 |
|---|---|
| Space / ↑ / W | 날갯짓 (게임 오버 화면에서는 다시하기) |
| 마우스 클릭 / 화면 탭 | 날갯짓 |
| Enter | 시작 / 다시하기 |
| P / Esc / Ⅱ 버튼 | 일시정지 / 계속하기 |

## 규칙
- 파이프 한 쌍을 지날 때마다 1점.
- 파이프, 땅, 천장에 닿으면 게임 오버.
- 10점 동메달 · 20점 은메달 · 40점 금메달.
- 최고 기록은 브라우저에 저장돼요 (저장이 막힌 환경에서는 이번 접속 동안만 유지).

## 실행
```bash
python -m http.server 8124 --directory flappy-bird
```
그다음 브라우저에서 http://localhost:8124 을 열면 돼요.
